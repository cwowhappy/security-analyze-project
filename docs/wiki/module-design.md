# 股票分析系统 — 功能模块划分

## 概述

本文档定义股票分析系统按业务域划分的功能模块及其职责边界。系统面向团队内部使用，覆盖 A 股（沪深京）上市公司数据查询与分析。

**文档目的**：为开发、测试及运维提供清晰的功能模块职责参考，明确各模块「做什么」与「不做什么」。

---

## 模块总览

| 模块 | 业务域 | 一句话职责 |
|------|--------|-----------|
| 公司信息模块 | 核心 | 提供上市公司基本信息、工商资料、行业分类等静态信息的查询与展示 |
| 证券信息模块 | 核心 | 提供上市证券的代码、名称、市场板块、上市状态等证券维度信息的查询与展示 |
| 财报数据模块 | 核心 | 提供季度与年度财务报告数据的查询、展示与基础财务指标计算 |
| 持仓管理模块 | 核心 | 提供用户股票组合的创建、成交记录录入、持仓汇总计算与盈亏分析 |
| Dashboard 总览模块 | 支撑 | 提供系统首页的数据概览、快捷入口与关键指标卡片 |
| 用户认证与权限模块 | 支撑 | 提供用户登录、JWT Token 管理、RBAC 角色权限控制 |
| 系统管理模块 | 支撑 | 提供用户管理、采集任务日志查看、系统配置等运维支撑功能 |
| 数据采集模块 | 数据采集 | 负责从外部数据源（akshare 等）定时采集公司、证券、财报、行情数据并写入数据库 |

---

## 逐模块职责说明

### 1. 公司信息模块

**所属层级**：前端 + 后端

**数据范围**：仅覆盖 A 股（沪深京）上市公司主体，不包含母公司、子公司、控股股东、关联方等扩展实体。

**列表页功能点**：
- **默认排序**：按股票代码升序排列
- **分页**：每页 20 条，支持页码跳转
- **搜索**：单关键词模糊搜索，同时匹配公司名称和股票代码
- **筛选**：首期不做独立筛选条件，搜索框即主要检索入口

**详情页 — Tab 页签结构**：

| Tab | 内容 |
|-----|------|
| **基本信息** | 公司名称、股票代码、所属行业、地区、成立日期、注册资本 |
| **关联证券** | 以平铺卡片展示该公司对应的所有证券（如 A 股、B 股），每张卡片展示证券基础信息 |
| **财务报告** | 快捷入口，跳转至该公司财报数据模块 |
| **历史变更** | 展示该公司的名称变更、行业分类调整、市场板块变动记录 |

**数据更新策略**：
- **手动触发更新**：需要更新时由运维/管理员手动执行采集任务
- **定期全量校验**：按配置周期（如每周/每月）自动跑一次全量校验，识别差异
- 不实时监听变更，以采集模块实际跑批结果为准

**不包含**：
- 不处理实时行情数据
- 不处理财务报告的具体科目数据（归属财报数据模块）
- 不执行数据采集任务（归属数据采集模块）
- 首期不覆盖工商登记信息中的法人、注册地址、统一社会信用代码等字段

---

### 2. 证券信息模块

**所属层级**：前端 + 后端

**职责范围**：
- 展示上市证券基础信息：股票代码、证券简称、市场板块（沪/深/京）、上市日期、上市状态
- 提供证券列表页，支持分页、排序、按市场板块筛选
- 展示证券与公司主体的关联关系（一对一或一对多）
- 提供证券详情页，作为该公司下所有信息的入口之一

**不包含**：
- 不包含股价 K 线、分时图等行情数据展示
- 不包含交易数据、换手率等市场行为数据
- 不执行数据采集任务（归属数据采集模块）

---

### 3. 财报数据模块

**所属层级**：前端 + 后端

**职责范围**：
- 展示季度与年度财务报告数据：资产负债表、利润表、现金流量表
- 支持按报告期（季度/年度）切换查看历史数据
- 提供基础财务指标的计算与展示：营收、净利润、毛利率、净资产收益率等
- 支持财务数据的表格展示与简单趋势图表（ECharts）
- 提供数据导出功能（预留，首期仅做页面展示）

**不包含**：
- 不包含复杂的财务模型分析（如 DCF 估值、同行业对比）
- 不包含财务数据的人工录入或修改功能
- 不执行数据采集任务（归属数据采集模块）

---

### 4. 持仓管理模块

**所属层级**：前端 + 后端 + 数据采集

**职责范围**：
- 提供用户创建、编辑、删除股票组合（Portfolio），支持实盘与模拟盘分类
- 支持录入完整成交记录：买入、卖出、现金分红、送股、配股、股份拆分（A股极少见）等
- 基于成交记录自动计算持仓汇总：当前持仓股数、平均成本、已实现盈亏
- 提供持仓列表与组合统计：总市值、浮动盈亏、已实现盈亏、收益率、仓位权重
- 关联公司信息模块，自动展示股票简称、行业、市场板块
- 盘后行情同步（数据采集侧）：每日拉取持仓股票的收盘价，支撑市值与浮动盈亏计算

**数据更新策略**：
- 成交记录由用户手动录入，录入后实时触发持仓重算
- 日行情数据由采集任务每日 15:30 自动同步，仅采集当前有持仓的股票代码

**不包含**：
- 不做实时行情与实时盈亏计算
- 不包含自动同步券商账户交易数据（仅支持手工录入与批量导入）
- 首期仅支持 A 股，不包含港股、美股等跨境市场
- 不包含复杂的资产配置模型或风险分析算法

---

### 5. Dashboard 总览模块

**所属层级**：前端 + 后端

**职责范围**：
- 提供系统首页，展示关键统计数字：上市公司总数、覆盖行业数、最新财报期数
- 提供快捷入口卡片：快速搜索公司、查看最新财报、进入证券列表
- 展示最近更新的数据时间戳
- 提供简单的数据更新状态提示

**不包含**：
- 不包含复杂的可视化大屏或实时数据看板
- 不包含个性化推荐算法

---

### 6. 用户认证与权限模块

**所属层级**：前端 + 后端

**职责范围**：
- 提供用户登录入口，支持用户名/密码认证
- 负责 JWT Token 的生成、刷新与校验
- 提供基于 RBAC 的接口级权限控制
- 定义基础角色：管理员（可访问全部功能）、普通用户（仅数据查询）
- 提供前端路由级别的权限拦截

**不包含**：
- 不包含第三方登录（OAuth、LDAP 等）
- 不包含多租户隔离
- 不包含细粒度的数据级权限控制（如按行业屏蔽数据）

---

### 7. 系统管理模块

**所属层级**：前端 + 后端

**职责范围**：
- 用户管理：查看用户列表、启用/禁用账号、分配角色（管理员功能）
- 采集任务日志查看：查看数据采集任务的执行历史、状态、影响行数
- 系统配置：数据库连接状态检查、基础参数配置

**不包含**：
- 不包含采集任务的在线启停控制（首期由运维直接操作采集容器）
- 不包含日志的归档与清理策略
- 不包含告警通知功能

---

### 8. 数据采集模块

**所属层级**：数据采集（Python）

**职责范围**：
- 从 akshare 等外部数据源获取 A 股上市公司列表、公司基本信息
- 获取上市证券的基础信息
- 获取季度与年度财务报告原始数据
- 负责数据清洗、格式转换与写入 PostgreSQL
- 内置定时调度器，按配置周期触发采集任务
- 记录每次采集任务的执行日志：任务名、起止时间、状态、影响行数
- 按（股票代码 + 报告期）去重，避免重复写入财务数据

**不包含**：
- 不直接向前端提供 API 服务
- 不处理业务逻辑计算（如财务指标计算归属后端）
- 不处理用户认证与权限
- 首期仅接入 akshare，不直接实现 Tushare/Wind 等商业接口（预留抽象扩展能力）
