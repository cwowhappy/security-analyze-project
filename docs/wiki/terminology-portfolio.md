# 证券交易与持仓管理 — 专业术语表

本文档整理持仓管理模块涉及的中文金融专业术语及其英文对照，统一项目内各文档、代码、接口的用语规范。

> **适用范围**：后端代码标识符、数据库字段、API 接口、前端界面文案、设计文档。

---

## 一、核心概念术语

| 中文术语 | 英文术语 | 说明 | 代码/字段映射 |
|---------|---------|------|--------------|
| **组合** | Portfolio | 用户定义的一组股票持仓集合，可对应一个或多个实际证券账户 | `portfolio` |
| **证券账户** | Securities Account | 用户在券商开立的实际交易账户；一个组合可映射一个账户 | `broker` 字段描述 |
| **股票持仓** | Stock Position / Equity Holding | 当前持有某只股票的汇总信息，含数量、成本、盈亏 | `position` |
| **成交记录** | Trade Record / Transaction | 每一笔买入、卖出或其他变动的明细记录 | `transaction_record`（表名保留，注释称成交记录） |
| **日K线** | Daily Candle / Daily Quote | 单个交易日的开盘价、最高价、最低价、收盘价、成交量、成交额 | `daily_quote` |
| **行情数据** | Market Data / Quote Data | 包含价格、成交量等市场公开信息的数据统称 | — |

### 术语辨析

- **组合（Portfolio）≠ 账户（Account）**：组合是用户在本系统内自定义的持仓分组概念；账户是券商层面的实体。一个组合可标注对应某个券商账户，但系统不直接对接券商账户。
- **股票持仓** vs **证券持仓**：本系统当前仅支持 A 股股票，故统一使用"股票持仓"。若后续扩展至基金、债券，再升级为"证券持仓"。
- **成交记录** vs **交易流水**："交易流水"偏银行/支付领域用语；证券交易领域标准用语为"成交记录"或"交易记录"。

## 二、交易相关术语

| 中文术语 | 英文术语 | 说明 | 代码/字段映射 |
|---------|---------|------|--------------|
| **成交日期** | Trade Date | 交易实际发生的日期（T日） | `trade_date` |
| **成交价格** | Trade Price / Execution Price | 单笔成交的价格；手工录入时以交割单"成交均价"为准 | `price` |
| **成交股数** | Trade Quantity / Shares | 成交的股票数量，单位：股（非手） | `quantity` |
| **成交数量** | — | 与"成交股数"同义，界面优先使用"成交股数" | — |
| **成交金额** | Trade Amount / Turnover | `成交价格 × 成交股数` | `amount`（系统计算） |
| **佣金** | Commission | 券商收取的交易佣金 | 归入 `fee` 字段，界面展示时可称"佣金及手续费" |
| **印花税** | Stamp Duty | 国家税务机关收取，A股仅卖出时征收（0.05%） | 归入 `tax` 字段 |
| **过户费** | Transfer Fee | 中登公司收取的股票过户费用 | 归入 `fee` 字段 |
| **交易费用** | Trading Fees | 佣金、过户费、交易经手费等费用的统称 | `fee` |
| **税费** | Taxes | 印花税、股息红利税等税费统称 | `tax` |
| **买入** | Buy / Purchase | 买入股票 | `BUY` |
| **卖出** | Sell | 卖出股票 | `SELL` |
| **现金分红** | Cash Dividend | 上市公司向股东派发现金 | `DIVIDEND` |
| **送股** | Bonus Issue / Stock Dividend | 上市公司以股票形式向股东分配利润 | `BONUS` |
| **转增股本** | Capitalization Issue | 以资本公积金向股东转增股票；对个人投资者持仓计算与送股效果相同 | 与 `BONUS` 合并处理 |
| **配股** | Rights Issue | 上市公司向现有股东按持股比例配售新股，股东需缴款认购 | `RIGHTS` |
| **送转股** | Bonus & Capitalization | 送股与转增股本的合称 | 对应 `BONUS` 交易类型 |
| **分红送股** | Dividend & Bonus | 现金分红、送股、转增的统称 | — |
| **除权除息** | Ex-Rights / Ex-Dividend | 分红送股后股价调整机制；系统通过录入对应交易类型反映 | — |

### 禁用/慎用术语

| 禁用/慎用 | 原因 | 推荐替代 |
|-----------|------|---------|
| ~~单价~~ | 偏商品零售领域 | **成交价格** |
| ~~数量~~（单独使用） | 过于笼统，未指明单位 | **成交股数** |
| ~~交易流水~~ | 偏银行/支付领域 | **成交记录** / **交易记录** |
| ~~交割单~~ | 特指券商出具的正式单据，系统内用"成交记录"更贴切 | **成交记录** |
| ~~拆股~~（Stock Split）| A股市场极少发生，且与送转股机制不同 | 如确需支持，称**股份拆分**；否则用**送转股** |
| ~~闭市~~ | 口语化 | **收盘** / **交易日结束** |

## 三、持仓与盈亏术语

| 中文术语 | 英文术语 | 说明 | 代码/字段映射 |
|---------|---------|------|--------------|
| **持仓数量** | Position Quantity / Holding Shares | 当前持有的股票股数 | `current_quantity` |
| **持仓成本** | Cost Basis | 累计买入投入（不含交易费用），即 `total_cost` | `total_cost` |
| **平均成本** | Average Cost | `持仓成本 ÷ 持仓数量`，即持仓均价 | `avg_cost` |
| **持仓市值** | Market Value of Position | `持仓数量 × 最新收盘价` | `market_value` |
| **组合总市值** | Total Market Value | 组合内所有持仓市值之和（不含现金余额） | `total_market_value` |
| **浮动盈亏** | Unrealized P&L / Floating P&L | 当前持仓按最新价计算的账面盈亏，未实际兑现 | `floating_pnl` |
| **浮动盈亏率** | Unrealized P&L Rate | `浮动盈亏 ÷ 持仓成本 × 100%` | `floating_pnl_rate` |
| **已实现盈亏** | Realized P&L | 卖出股票后实际兑现的盈亏 | `realized_pnl` |
| **累计盈亏** | Total Return / Cumulative P&L | `浮动盈亏 + 已实现盈亏`，即总损益 | `total_asset_return` |
| **收益率** | Return Rate / Yield | 累计盈亏相对投入本金的比例 | `total_asset_return_rate` |
| **仓位占比** | Weight / Allocation | 单只持仓市值占组合总市值的比例 | `weight` |
| **仓位** | Position Sizing | 泛指持仓占资金的比例；单票比例称"仓位占比" | — |
| **清仓** | Close Position / Liquidate | 将某只股票全部卖出，持仓数量归零 | — |
| **建仓** | Open Position | 首次买入某只股票，形成持仓 | — |
| **加仓** | Add to Position | 在已有持仓基础上继续买入 | — |
| **减仓** | Reduce Position | 卖出部分持仓 | — |
| **停牌** | Trading Halt / Suspension | 股票暂停交易，无最新收盘价 | — |

### 术语辨析

- **持仓市值 ≠ 总资产**：`组合总市值`仅统计股票市值，不含账户现金余额。若未来扩展至支持现金管理，再引入"总资产"概念。
- **持仓成本 ≠ 总投入**：`持仓成本`（`total_cost`）不含佣金、印花税等交易费用；交易费用计入`fee`和`tax`，在计算已实现盈亏时扣除。
- **浮动盈亏** vs **当日盈亏**：浮动盈亏是"当前价 vs 成本价"的累计视角；当日盈亏是"今日收盘价 vs 昨日收盘价"的日间视角。当前系统以浮动盈亏为主，当日盈亏需额外计算，不在 MVP 范围内。
- **平均成本法**：本系统采用加权平均成本法（Weighted Average Cost），即每次买入后重新计算平均成本；卖出时按当前平均成本扣减。

## 四、行情与数据术语

| 中文术语 | 英文术语 | 说明 | 代码/字段映射 |
|---------|---------|------|--------------|
| **收盘价** | Close Price | 交易日结束时的最后成交价 | `close_price` |
| **开盘价** | Open Price | 交易日开始时的首笔成交价 | `open_price` |
| **最高价** | High Price | 交易日内的最高成交价 | `high_price` |
| **最低价** | Low Price | 交易日内的最低成交价 | `low_price` |
| **成交量** | Volume | 交易日内成交的总股数 | `volume` |
| **成交额** | Turnover / Amount | 交易日内成交的总金额 | `amount`（日线表） |
| **盘后同步** | Post-Market Sync | 收盘后从数据源拉取当日行情数据 | — |
| **定向采集** | Targeted Collection | 仅采集当前有持仓的股票行情，非全市场扫描 | 原称"增量采集"，已修正 |
| **前复权** | Forward Adjustment | 对历史股价进行分红送股调整，保持当前价格连续性 | 预留，MVP 不做 |
| **除权价** | Ex-Rights Price | 分红送股后调整的价格 | — |

### 禁用/慎用术语

| 禁用/慎用 | 原因 | 推荐替代 |
|-----------|------|---------|
| ~~增量采集~~（行情）| "增量"指仅采集新增/变化数据；此处实际是按需、定向采集 | **定向采集** / **按需采集** |
| ~~日行情~~ | 可接受，但"日K线"更专业 | **日K线** / **日线数据** |
| ~~总资产~~（指股票市值）| 易误解为含现金余额 | **组合总市值** / **持仓市值** |
| ~~市值~~（单独使用）| 需明确是个股市值还是组合总市值 | **持仓市值** / **组合总市值** |

### 前端页面应使用的术语

| 场景 | 推荐文案 | 禁用文案 |

| 分红送股录入 | 现金分红、送股、转增股本 | 分红、bonus |
