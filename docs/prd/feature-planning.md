### 1.3 数据模型说明

系统使用三张核心表构建基础信息底座（v2.0 简化模型）：

```
tb_stock_basic          ← 股票基础信息（含 company_id 外键直接关联公司）
tb_company_basic        ← 公司工商信息
tb_collection_task      ← 采集任务执行记录
```

> **设计原则**：A 股股票与公司本质为 1:1 映射，废弃关联表以降低查询复杂度，`tb_stock_basic` 通过 `company_id` 外键直接关联 `tb_company_basic`。定时规则由采集器内部 APScheduler 管理，不持久化到数据库。
>
> 详见 `docs/wiki/data-model-stock-company-collection.md`（v2.0）。

### 2.3 采集策略设计

#### 数据源分工

| 数据类别 | 主数据源 | 备用数据源 | 互补说明 |
|---------|---------|----------|---------|
| 股票列表与基础信息 | AKShare | Tushare | Tushare 补充 area、实控人信息 |
| 公司工商信息 | AKShare `stock_profile_cninfo` | Tushare `stock_company` | Tushare 补充管理层、员工数、统一信用代码 |
| 完整财务报表 | Tushare Pro | AKShare（有限）| AKShare 财务字段不完整，Tushare 作主源 |
| 实时/历史行情 | AKShare | Tushare / BaoStock | — |
| 分钟级数据 | AKShare | — | Tushare 不支持分钟数据 |

#### 降级机制

```
调用主数据源（AKShare）
    ├── 成功 → 写库，继续下一条
    ├── SourceUnavailableError / SourceRateLimitError
    │       → 指数退避重试（最多3次，基础延迟3秒）
    │       → 仍失败 → 切换备用源（Tushare）
    │       → 备用源也失败 → 记录 fail_count，跳过本条
    └── SourceDataError（格式异常/字段缺失）
            → 尝试备用源
            → 仍失败 → 记录跳过
```

#### 限流控制

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `SOURCE_MAX_RETRIES` | 3 | 单条记录重试次数 |
| `SOURCE_RETRY_DELAY` | 3 秒 | 重试基础延迟 |
| `SOURCE_RETRY_BACKOFF` | 2（倍数）| 指数退避倍数 |
| `SOURCE_REQUEST_DELAY_MIN` | 1 秒 | 请求间最小随机延迟 |
| `SOURCE_REQUEST_DELAY_MAX` | 3 秒 | 请求间最大随机延迟 |
| `FINANCE_MAX_WORKERS` | 1 | 财务数据并发（东方财富敏感，建议为1）|
| APScheduler `max_workers` | 5 | 整体最大并发线程数 |

## 三、证券分析（基本面 + 高级指标）

> **目标**：从"查数据"到"出观点"，支持基本面深度分析与高级量化指标计算，辅助投资决策。

### 3.1 基本面分析

#### 财务报表分析

| 分析维度 | 具体指标 | 数据来源 | 优先级 |
|---------|---------|---------|--------|
| **利润表分析** | 营业收入、营业成本、毛利率、净利率、归母净利润、扣非净利润、研发费用 | Tushare `income` | P0 |
| **资产负债表分析** | 总资产、流动资产、非流动资产、货币资金、应收账款、存货、总负债、股东权益、商誉 | Tushare `balancesheet` | P0 |
| **现金流分析** | 经营活动净现金流、投资活动净现金流、筹资活动净现金流、自由现金流（FCF）、资本开支 | Tushare `cashflow` | P0 |
| **同比/环比对比** | 营收增速、净利润增速、现金流增速（YoY/QoQ）| Tushare `fina_indicator` | P0 |
| **历史趋势图表** | 近8~12个季度核心指标趋势可视化 | Tushare 历史数据 | P1 |

#### 盈利能力指标

| 指标名称 | 说明 | 计算方式 |
|---------|------|---------|
| **ROE**（净资产收益率）| 股东权益回报能力 | 净利润 ÷ 平均净资产 |
| **ROA**（总资产收益率）| 资产运营效率 | 净利润 ÷ 平均总资产 |
| **ROIC**（投入资本回报率）| 实际投入资本的回报效率 | EBIT×(1-税率) ÷ 投入资本 |
| **毛利率**（Gross Margin）| 主营业务盈利空间 | 毛利 ÷ 营业收入 |
| **净利率**（Net Margin）| 最终盈利能力 | 净利润 ÷ 营业收入 |
| **EBITDA** | 经营层面现金盈利能力 | 净利润+利息+税+折旧+摊销 |

#### 偿债能力指标

| 指标名称 | 说明 |
|---------|------|
| **资产负债率** | 总负债 ÷ 总资产（< 60% 通常较健康）|
| **流动比率** | 流动资产 ÷ 流动负债（> 1.5 较安全）|
| **速动比率** | （流动资产 - 存货）÷ 流动负债 |
| **净负债率（Gearing）**| (有息负债 - 现金) ÷ 净资产 |
| **利息覆盖倍数** | EBIT ÷ 利息支出（> 3 较安全）|

#### 运营效率指标

| 指标名称 | 说明 |
|---------|------|
| **应收账款周转天数（DSO）**| 回款速度，越小越好 |
| **存货周转天数（DIO）**| 存货消化速度 |
| **应付账款周转天数（DPO）**| 对供应商的占款能力 |
| **现金转换周期（CCC）**| DSO + DIO - DPO，反映营运资本效率 |
| **总资产周转率** | 单位资产的销售额 |

#### 成长性指标

| 指标名称 | 说明 |
|---------|------|
| **营收增速（Revenue CAGR）**| 近3年复合增速 |
| **归母净利润增速（NP CAGR）**| 近3年复合增速 |
| **扣非净利润增速** | 剔除非经常性损益的增速 |
| **经营现金流增速** | 验证利润质量 |

### 3.2 估值分析

#### 相对估值法

| 指标 | 计算公式 | 适用场景 | 数据来源 |
|------|---------|---------|---------|
| **PE（市盈率）** | 市值 ÷ 归母净利润 | 稳定盈利型公司 | Tushare `daily_basic` |
| **PE-TTM** | 市值 ÷ 近12个月净利润 | 动态盈利跟踪 | Tushare `daily_basic` |
| **PB（市净率）** | 市值 ÷ 净资产 | 银行/地产/资源型 | Tushare `daily_basic` |
| **PS（市销率）** | 市值 ÷ 营收 | 亏损/早期成长型 | Tushare `daily_basic` |
| **PEG** | PE ÷ 净利润增速（%）| 成长股估值修正 | 计算所得 |
| **EV/EBITDA** | 企业价值 ÷ EBITDA | 重资产/周期性行业 | 计算所得 |
| **股息率** | 股息 ÷ 股价 | 高股息策略 | Tushare `daily_basic` |

#### 估值历史分位

| 功能 | 说明 | 优先级 |
|------|------|--------|
| PE/PB 历史百分位 | 展示当前估值处于历史高/低位 | P0 |
| 行业平均估值比较 | 个股估值相对行业均值的溢价/折价 | P1 |
| 估值区间标注 | 在K线图上标注历史估值高低区间 | P2 |

#### AI 辅助分析
