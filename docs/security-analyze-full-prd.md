# 个人投研系统 · 产品功能文档

> 版本：v1.0 | 日期：2026年5月9日 | 作者：李晓毅

---

## 一、产品定位

### 1.1 一句话定义

**为个人投资者打造的 AI 驱动投研操作系统**——从信息采集、数据分析到投资决策，全链路提效，让一个人的研究能力比肩一个小团队。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **策略驱动** | 系统围绕你的投资策略服务，不是大而全的信息堆砌，而是"从噪音中提取信号" |
| **AI 原生** | 大模型不是辅助工具，而是系统中枢——自主规划任务、调用数据、生成观点、交叉验证 |
| **数据为王** | 数据质量决定分析质量，宁可多花成本，不在数据上省出亏损 |
| **闭环迭代** | 信息采集 → 分析研究 → 决策执行 → 复盘优化，形成可迭代的闭环 |
| **渐进构建** | MVP 先跑通核心链路，再逐步扩展高级功能，避免过度设计 |

### 1.3 目标用户画像

- 有一定投资经验（2年+），从"听消息炒股"向"系统化投研"进化
- 关注 A 股，兼顾宏观与行业，偏好基本面+事件驱动策略
- 时间有限，需要工具提效，而非替代判断
- 具备基础技术能力（能跑 Python、调 API），但不追求量化高频交易

## 二、系统架构总览

```
┌─────────────────────────────────────────────────────────────────┐
│                      个人投研系统架构                             │
│                                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │  信息采集  │  │  数据中台  │  │  AI 研究引擎 │  │  决策与执行 │        │
│  │  Layer 1  │→│  Layer 2  │→│  Layer 3  │→│  Layer 4  │        │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘        │
│       ↑              ↑              ↑              ↑             │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                    基础设施层 Layer 0                      │   │
│  │  数据库 · 消息队列 · 任务调度 · 日志监控 · 权限管理          │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                    交互入口层 Layer 5                      │   │
│  │  Web 仪表盘 · 移动端通知 · IM 消息推送（微信/飞书/钉钉）    │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 各层职责

| 层级 | 名称 | 核心职责 |
|------|------|---------|
| **Layer 0** | 基础设施 | 数据存储、任务调度、消息推送、系统运维 |
| **Layer 1** | 信息采集 | 多源数据自动抓取、清洗、入库 |
| **Layer 2** | 数据中台 | 统一数据模型、指标计算、因子库、时序存储 |
| **Layer 3** | AI 研究引擎 | 大模型驱动的智能分析、Agent 编排、报告生成 |
| **Layer 4** | 决策与执行 | 策略管理、组合跟踪、风控预警、交易辅助 |
| **Layer 5** | 交互入口 | 可视化看板、消息推送、移动端访问 |

## 三、功能模块详细设计

### 模块一：信息采集中心

> **目标**：从"被动搜索"到"主动推送"，让关键信息找你

| 子功能 | 说明 | 优先级 |
|--------|------|--------|
| 定期报告监控 | 年报/半年报/季报披露自动抓取，关键词提取 | P0 |
| 业绩预告/快报 | 业绩预告、快报第一时间推送 | P0 |
| 重大事项公告 | 增减持、重组、再融资、股权激励等 | P0 |
| IPO/再融资日历 | 新股申购、解禁、增发等日程提醒 | P1 |

#### 1.3 研报与机构观点

|--------|------|--------|
| 券商研报聚合 | 行业研报、个股研报自动采集，关键词/行业/券商检索 | P0 |
| 评级变动追踪 | 机构评级上调/下调、目标价变动汇总 | P0 |
| 电话会/业绩会纪要 | 管理层讨论、业绩会纪要采集 | P1 |
| 调研记录 | 机构调研活动与调研纪要 | P1 |

#### 1.4 新闻与舆情

> **目标**：从"查数据"到"出观点"，AI 自主完成研究闭环

| 子功能 | 说明 | 优先级 |
|--------|------|--------|
| 公司研究 Agent | 输入股票代码，自动完成基本面/财务/估值/竞争力分析 | P0 |
| 行业研究 Agent | 输入行业名称，自动梳理产业链/竞争格局/投资逻辑 | P0 |
| 宏观研究 Agent | 追踪宏观指标变化，分析对市场/行业的影响 | P1 |
| 事件分析 Agent | 突发事件自动拆解，分析影响标的与方向 | P0 |
| 财报解读 Agent | 季报/年报自动解读，核心变化提取与同比环比分析 | P0 |

#### 3.2 Deep Research 深度研究

| 子功能 | 说明 | 优先级 |
|--------|------|--------|
| 自动拆解子问题 | 将复杂研究任务自动拆解为可执行的子任务链 | P0 |
| 跨源检索与交叉验证 | 多数据源交叉验证，标注引用来源 | P0 |
| 研究初稿生成 | 自动生成带数据、图表、引用的结构化研究初稿 | P1 |
| 研究框架模板 | 内置行业分析/公司分析/策略分析框架模板 | P1 |

#### 3.3 知识管理

| 子功能 | 说明 | 优先级 |
|--------|------|--------|
| 个人知识库 | 上传研报/笔记/文章，构建私有知识库 | P0 |
| 研究框架沉淀 | 将分析框架模板化、可复用 | P1 |
| 观点追踪 | 追踪自己/他人的历史观点与验证情况 | P2 |
| AI 问答 | 基于知识库的智能问答，支持多轮对话 | P0 |

#### 3.4 内容生成

| 子功能 | 说明 | 优先级 |
|--------|------|--------|
| 晨报/日报自动生成 | 每日市场复盘、关键事件、持仓影响汇总 | P0 |

## 四、数据源与获取途径

│              数据源分层策略                         │

## 七、风险与注意事项

| 风险类型 | 说明 | 应对措施 |
|---------|------|---------|
| **数据源不稳定** | 免费爬虫源随时可能失效（如Tushare停运事件） | 核心数据多源冗余，自动降级 |
| **AI幻觉** | 大模型生成内容可能包含错误数据或逻辑 | 所有关键数据交叉验证，AI输出标注"需核实" |
| **数据合规** | 爬虫采集可能违反网站ToS | 遵守robots.txt，优先使用官方API，控制请求频率 |
| **信息安全** | API Key泄露、持仓数据暴露 | Key加密存储，数据本地优先，云端传输加密 |
| **过度依赖** | 系统越强大，越可能替代独立思考 | 系统定位为"辅助工具"，最终决策权在人 |
| **成本失控** | API调用费用可能快速增长 | 设置调用配额与成本告警 |
| **过度设计** | 追求大而全，迟迟无法落地 | 严格按Phase推进，每阶段交付可用功能 |
